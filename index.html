核心技术

五大技术壁垒，
重新定义智能盲杖

行业首创"双雷达同轴布局+本地多模态AI"架构，核心元件100%国产化，从感知、智能、隐私、成本、体验五个维度构建护城河。

📡
TECH 01

双雷达同轴布局

前向雷达（0.2-12m）负责远距离障碍物与空中悬挂物预警；下向雷达（0.1-3m）负责台阶、坑洼、路沿精准识别。不受光线、雨雾、人流遮挡影响，7×24小时稳定工作。

🧠
TECH 02

轻量化AI识别算法

基于PyTorch框架，通过5000+张真实出行场景标注数据训练，覆盖台阶、坑洼、共享单车、商铺等12类障碍物，识别准确率≥95%，误报率<5%。

💬
TECH 03

本地多模态大模型导航

部署量化后的轻量大语言模型，实现沿街商铺识别、公共设施查询、最优路径规划。所有数据本地处理，无需联网，响应更快，隐私更安全。

🔒
TECH 04

硬件级隐私防护

行业首创"摄像头物理断电拨杆"——拨杆关闭时同时切断电源和信号线，从硬件底层杜绝静默采集。配合"按需唤醒"和"全数据本地处理"形成三重防护。

✋
TECH 05

多模态无障碍反馈

触摸按键 + 分级震动 + 定向传音 + 蓝牙耳机四通道反馈，视障用户无需培训即可上手。可完全替代传统盲杖，零学习成本。

发展路线

三步走战略，
从上海到全国

PHASE 1

上海落地，跑通模式 2026年

完成小批量试产1000台，联合3家盲校、5个区残联完成公益试点，实现首批500台销售，第8个月实现盈亏平衡。进入上海市残联辅助器具采购目录。

PHASE 2

上海全覆盖，辐射长三角 2027-2028年

覆盖上海所有区县，累计销售突破3000台。在苏州、杭州、宁波等长三角城市设立合作体验点，推出"视障生活服务平台"APP内测版。

PHASE 3

全国标杆，产品矩阵 2029-2030年

累计销售1万台以上，年营收突破5000万元。开发轻量版（¥599）和高端版（¥1599），拓展至听障、肢残辅助器具领域，形成无障碍产品矩阵。
